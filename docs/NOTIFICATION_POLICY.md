# WOLI 집중 알림 판단 기준

월이는 모든 메신저 알림을 읽어주는 앱이 아니라, 집중 중에도 놓치면 안 되는 연락만 남기는 디지털 디톡스 보조 앱입니다.

## 기본 원칙

1. 일반 카카오톡, 문자, DM은 기본적으로 음성 안내하지 않습니다.
2. 중요 연락처에서 온 알림은 음성 안내합니다.
3. 중요 연락처 알림에 긴급 표현이 있으면 긴급 알림으로 올립니다.
4. 알람, 일정, 리마인더는 중요한 시간성 알림으로 안내합니다.
5. 광고, 쿠폰, 좋아요, 댓글, 추천, 묶음 요약, 음악 재생 중, 백그라운드 상태 알림은 안내하지 않습니다.
6. 시연이 필요할 때만 `시연` 모드로 답장 가능한 테스트 메시지를 안내합니다.

## 정책 모드

| 모드 | 목적 | 안내 대상 |
|---|---|---|
| 집중 우선 | 실제 집중 사용 | 전화, 중요 연락처, 알람/일정 |
| 균형 | 기본값, 공모전 시연과 실사용 균형 | 전화, 중요 연락처, 긴급 표현, 허용 앱 |
| 시연 | 발표 중 답장 흐름 확인 | 균형 모드 + 답장 가능한 테스트 메시지 |

기본값은 `균형`입니다. 일반 메신저는 이 모드에서도 바로 안내되지 않고, 중요 연락처, 긴급 표현, 사용자가 허용한 앱 조건 중 하나를 만족해야 합니다.

## 시연 권장 설정

1. 설정 > 중요 연락처에서 테스트 연락처를 등록합니다.
2. 설정 > 집중 알림 기준에서 `균형` 모드를 선택합니다.
3. 카카오톡 또는 문자 메시지는 기본적으로 제외된다고 설명합니다.
4. 중요 연락처에서 메시지를 보내 `중요 연락처` 판단 기준이 표시되는지 확인합니다.
5. 같은 연락처가 `긴급이야 지금 전화해줘` 같은 메시지를 보내면 긴급 알림으로 올라가는지 확인합니다.
6. 답장 기능까지 보여줘야 하면 `시연` 모드로 바꾸고 테스트 메시지를 보냅니다.

## 한계

- 앱마다 알림 제목, 본문, 단체방 여부를 Android에 제공하는 방식이 다릅니다.
- 일부 메신저는 단체방 여부를 명확히 제공하지 않을 수 있습니다.
- 실제 답장 가능 여부는 Android `RemoteInput` 제공 여부에 따라 달라집니다.
- 실기기에서 카카오톡, 문자, Telegram, WhatsApp을 각각 검증해야 최종 시연 안정성을 판단할 수 있습니다.
