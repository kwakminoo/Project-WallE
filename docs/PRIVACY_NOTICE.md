# WOLI 개인정보 및 권한 안내

월이는 집중 중 중요한 연락만 안내하고, 사용자가 음성으로 답장 여부를 선택할 수 있도록 돕는 Android 앱입니다.

## 수집하거나 접근하는 정보

월이는 다음 정보를 단말 안에서만 사용합니다.

- 중요 연락처 이름과 전화번호
- 알림 제목, 앱 이름, 간단한 본문 요약
- 답장 전송 성공/실패 이력
- 전화 수신 상태와 발신자 정보
- BLE 기기 연결 상태와 하드웨어 센서 상태

현재 저장소 기준으로 외부 서버, 클라우드 DB, 원격 분석 SDK로 데이터를 전송하지 않습니다.

## 권한 사용 목적

| 권한 | 목적 |
|---|---|
| 알림 접근 | 집중 중 중요 알림 감지 및 TTS 안내 |
| 알림 표시 | 포그라운드 서비스 실행 상태 표시 |
| 연락처 | 저장된 중요 연락처와 알림/전화 발신자 매칭 |
| 전화 상태 | 수신 전화 감지 |
| 통화 기록 | 가능한 기기에서 발신자 번호 식별 |
| 전화 제어 | 가능한 기기에서 받기/거절 명령 시도 |
| 마이크 | 음성 명령 및 답장 초안 입력 |
| Bluetooth | ESP32 월이 기기 검색, 연결, 잠금 명령 |
| 카메라 | 향후 시선/상태 인식 확장 대비 |

## 저장 위치와 삭제

- 중요 연락처, 집중 세션, 답장 이력은 앱 로컬 저장소에 저장됩니다.
- 앱을 삭제하면 로컬 데이터도 함께 삭제됩니다.
- 시연 전에는 개인 계정 대신 테스트 계정과 발표용 연락처를 사용하는 것을 권장합니다.

## 한계

- Android 제조사, OS 버전, 메시지 앱 정책에 따라 답장/전화 제어가 실패할 수 있습니다.
- 알림 접근 권한이 꺼져 있으면 월이가 메시지 내용을 알 수 없습니다.
- 배터리 최적화가 강한 기기에서는 백그라운드 TTS나 BLE 유지가 중단될 수 있습니다.
